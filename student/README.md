# Student Management System

## Project Description

The Student Management System is a web application developed using JavaScript and React. It allows users to manage student records through an interactive dashboard.

Users can view, add, edit, delete, and search for student records.

## Features

- View student records in a structured table.
- Add new student records.
- Edit existing student information.
- Delete student records with a confirmation dialog.
- Search for students.
- Validate student information before saving.
- Display the total number of students.
- Save student records in local storage so they remain available after refreshing the page.
- Use modal dialogs to add and edit student information.

## Student Information

Each student record includes:

- Student ID
- Full Name
- Age
- Email Address
- Course of Study
- Enrollment Status

## Technologies Used

- HTML
- CSS
- JavaScript
- React
- Vite

## Installation and Setup

### Requirements

Install Node.js on your computer.

### Steps

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install the project dependencies by running:

   npm install

5. Start the development server by running:

   npm run dev

6. Open the local address displayed in the terminal in your web browser.

## How to Use the Application

1. Open the Student Management System.
2. View the student records in the dashboard.
3. Click Add Student to add a new record.
4. Click Edit to update an existing student record.
5. Click Delete to remove a student record after confirming the action.
6. Use the search box to find a student.
7. Refresh the page to check that saved student records remain available.

## Data Storage

The application uses the browser's local storage to save student records. The records remain available after refreshing the page in the same browser.

## Project Purpose

This project demonstrates the use of JavaScript data types, variables, functions, React components, state management, event handling, form validation, and modal dialogs.
